# frog_pan (2026-11-18) — FAIL (trial 1)

**Hypothesis.** Momentum that arrived through many small up-days (low information discreteness) drifts longer than momentum from a few jumps (investor inattention).
**Source.** Da, Gurun, Warachka, RFS 27(7) 2014 (citation confirmed; abstract read, full text not). Seed idea from US-centred literature; no Indian test found (research/india_evidence.md). Effect is published, likely weaker now.
**Small-account fit (decided before testing).** top_n 10, buffer 5, 12-1 formation; monthly vs quarterly cadence to limit INR 15.34 sell charges.
**Grid (fixed before eval).** M and Q cadence, lookback 252, skip 21.
**Score.** 0.5 pct-rank(12-1m return) + 0.5 pct-rank(-ID), ID = sign(PRET)*(%neg days - %pos days).

## Learned
- Not an affordability failure: charges were only 1.05%/yr and the book was invested only 10-56% of the time (bear exit/regime filter). The failure is simply no edge over the index at this size.
- Implementation flaw noticed AFTER the result (while writing a unit test, which first failed): ID is sign-adjusted, so a *smooth loser* gets a high ID rank. For a long-only book this adds a bit of noise; the paper's sort is within winners/losers. NOT fixed in this run (rule: no tweak-and-rerun). Variant for a later run: "frog_pan_winners" = apply ID rank only to PRET>0 stocks. Counts as a new trial.
- Tests: the unit test was adjusted to winners-only after the flaw was found; the scoring code itself is unchanged since evaluation.
