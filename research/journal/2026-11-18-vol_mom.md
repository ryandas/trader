# vol_mom: volatility-adjusted momentum ranking (trial 6)

## Hypothesis
Momentum crashes concentrate in high-volatility names and periods. Ranking on 12-1 month return divided by trailing realised daily volatility should favour smoother winners, cut crash losses and keep most of the average return.

## Source
Barroso & Santa-Clara (2015), "Momentum has its moments", JFE 116(1). Abstract seen via search 2026-11-18; full text not opened. Deviation: the paper scales the momentum portfolio's exposure over time. The rotation contract can only rank names, so this tests a risk-adjusted ranking, a different idea. NSE's Nifty200 Momentum 30 also uses a volatility-adjusted score (see `research/india_evidence.md`), which gives some Indian methodological support, but no rigorous Indian test of this exact ranking was found.

## Pre-test checks (no backtest results used)
- (a) Evidence outside the US: none found for the ranking version. The seed idea was written from US-centred memory.
- (b) Small-account fit: monthly rebalance, 5 or 10 names. With 5 names each position is about INR 1,000, so a DP sale charge of INR 14.75 is about 1.5% per sale. Turnover is moderate because of the buffer.
- Queue refill: not done in this scheduled run (no WebSearch). 1 backtestable idea (`regime_switch`) remains in the queue; a later interactive run should refill it.

window 63 or 126 x (top_n 5, buffer 2) or (top_n 10, buffer 5); rebalance M; bear_exit on.

## Controls
Index 12.74%, equal-weight basket 16.13%, random-pick median 5.74%, default momentum 11.28%, full universe 17.12%. Max drawdown -21.25%.

Account sizes: INR 5,000 13.83% (2/6 years); 25,000 14.23% (3/6); 100,000 17.52% (4/6). No merit at 100,000 either.

## Verdict
FAIL. Deciding gates: beats_index_and_basket (it beat the index by about 1 point but not the basket), beats_index_most_years (2/6), robust_across_grid and DSR 0.678. Only the 63-day, 5-name point beat the index (14.23%). The result is not explained by a cost or affordability effect (charges 1.38%/yr).

## What I learned
Dividing by volatility did beat default momentum (11.28%) and random picks, but it does not beat a passive index in a robust way. Results depend on the grid point. A variant would be a new trial.
